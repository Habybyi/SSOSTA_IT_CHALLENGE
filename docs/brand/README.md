# Značka Custodia

Podklady od grafikov. Slogan: **Kráľovsky bez starostí**.

## Farby

| Názov | HEX | Použitie v CRM |
|---|---|---|
| Primary | `#28861C` | Tlačidlá, aktívne prvky, ikonky |
| Secondary | `#0A2E0F` | Logo, nadpisy, tmavé plochy |
| Accent | `#97C677` | Svetlé zvýraznenie |

Gradienty: svetlý `#97C677` → `#28861C`, tmavý `#0A2E0F` → `#28861C`. Celý prehľad je v [style-guide-farby.pdf](style-guide-farby.pdf).

## Logá (`svg/`)

| Variant | Čo to je | Kde v CRM |
|---|---|---|
| `lockup` | Znak + názov + slogan | Prihlásenie, zmena hesla |
| `primary` | Znak + názov pod sebou | Bočné menu |
| `secondary` | Znak + názov vedľa seba | Hlavička na mobile |
| `mark` | Len znak (koruna) | Zbalené menu, ikonka v prehliadači |
| `wordmark` | Len názov | Kde nie je miesto na znak |

Každý variant má 4 farebné verzie: `dark` (na svetlé pozadie), `light` (na tmavé pozadie, farebné), `white` a `black` (jednofarebné, napr. tlač, polep).
